# 临界聚焦动力学

**相干结构、占据谱阈值与塌缩**  
Shuxing Yang

[研究总论](RESEARCH.zh-CN.md) · [全部结果](RESULTS.md) · [完整目录](CONTENTS.md) · [研究脉络](HISTORY.md) · [文献](references/README.md) · [计算复现](COMPUTATIONS.md)

这项研究考察：色散、质量、动量与守恒模态占据如何共同决定聚焦波的长期相干运动、集中阈值和塌缩行为。

研究从非径向负能量全局解出发，得到三个相互连接的部分。

- **负能量全局动力学与质量间隙。** 激发态的负动量响应产生三维、四维双调和行波；双核心与核心加辐射实现总动量抵消；临界优化子附近的相位强制性排除低质量负能量行波，并给出定量残差约束及混合阶色散推广。
- **占据谱决定的阈值与临界核心。** 在共同密度非线性系统中，完整 Gram 谱保持不变。特定占据范围内的精确阈值、主模态核心与规则背景分解、输运和共形分析，把静态锐不等式连接到实际演化。
- **正交代价与集体束缚。** 多模态密度叠加增加吸引，正交约束增加动能。分离核相互作用、全尺度散射、矩阵余项和完整谱响应研究这场竞争；一般二维锐 Lieb–Thirring 问题在本研究中仍未解决。

第一篇工作的题目保持为 **《质量临界色散方程中的负能量全局解与行波质量间隙》**，其[摘要与证明顺序](papers/negative-energy/README.md)集中列出。仓库同时保留本会话的占据谱、临界尺度、集体束缚和光学延拓工作，避免把不同方程下的结论混成同一个定理。
