# R31：二维锐正交 GN 猜想——完整谱响应与梯度修正的反例

日期：2026-10-18。

## 主目标与本轮状态

目标始终是对任意有限正交族证明
`T ≥ K₁ F`，其中
`T = Σᵢ ∫|∇φᵢ|²`、`F = ∫(Σᵢ|φᵢ|²)²`、
`K₁ = M_c/2`，`−ΔQ+Q−Q³=0`、`M_c=∫Q²`。

**本轮没有证明原猜想，没有提高全局常数，也没有排除一个新的完整秩范围。**
完成的是一个精确响应恒等式、一组可复现的定向数值校准，
以及对一类曾考虑过的普遍梯度修正不等式的解析反例。
三者的证明地位不能混同。

## 1. 完整响应相对受限变分的精确修正

在自洽候选
`Hφᵢ=−eᵢφᵢ`、`H=−Δ−aρ`
处，令 P 为已占据空间的投影，Π=I−P，
`Aᵢ=Π(H+eᵢ)Π>0`，A 为其直和，
`BY=ΣᵢφᵢYᵢ`，`Q_lin=A−2aB*B`。

对任意适当正则的水平切向量 Y，取 W=2BY、Z=Q_lin Y，有精确恒等式

`(2a)⁻¹‖W‖₂² − ⟨W,BA⁻¹B*W⟩
 = a⁻²[⟨Y,Q_lin Y⟩ − ⟨Z,A⁻¹Z⟩].`

第二项是非负的。因此允许全部未占据态调整，可以改进一个受限轨道试探。
**完整轨道 Hessian 与完整势响应仍然等价；这里没有获得一个逻辑上更强的总条件。**

本轮核对了不同占据频率、非径向轨道、内部简并时的投影伸缩公式。
只要求占据空间上方有谱隙，不要求已占据全部负谱。
详情：[response-schur.md](response-schur.md)。

尚未证明这个非负修正对每个 a<M_c 的假想违例优化子都足够大。
导数扰动有限维空间是否普适足够，也没有证明。

## 2. 一次有明确对照的数值校准

输入为 R24 已有三模态驻波，参数 a≈12.80583924 > M_c≈11.7008965。
它是已知鞍点，**不处于假想反例所需的 a<M_c 范围**。
使用同一个投影 resolvent，保留额外未占据束缚态及大区域连续谱近似。
响应比的失稳阈值为 1。

| 扰动或响应限制 | 最大响应比，R=65、h=0.0025 |
|---|---:|
| 无迹二次势空间 | 0.95470443 |
| 完整对称二次势空间 | 0.95470443 |
| 两个尺度导数势，仅允许独立轨道缩放响应 | 1.21242529 |
| 两个尺度导数势，完整未占据谱响应 | 1.36436831 |
| 共同缩放对照，精确值应为 1 | 1.00000286 |

最佳导数势约为 `W_g − 0.31963917 W_f`，
`W_f=f(f+rf′)`、`W_g=g(g+rg′)`。

网格加密与区域扩大结果见 JSON 和校准笔记。
这是数值收敛检查，**不是区间算术证明，更不是普遍失稳定理**。
它具体说明：原来的二次势空间会漏掉已知鞍点，
空间导数方向和完整轨道调整确实能恢复失稳检验。

## 3. 普遍线性梯度修正不能回收锐常数

令 `W_F=∫|∇√ρ|²`。本轮解析证明：
对每个固定 η>0，
`T+ηW_F ≥ (1+η)K₁F`
都不可能对所有正交族成立，秩二已足够。

构造为两个远离的归一化 Townes 态的精确正交投影。
记 D=T−K₁F、G=T−W_F，`q(r)~A r⁻¹ᐟ²e⁻ʳ`，有

`D ~ 8πA⁴e⁻²ᴿ > 0`（复用 R22 既有结果），
`G ~ √2 π³ᐟ² A² R⁻¹ᐟ²e⁻ᴿ`（本轮补全全空间渐近证明）。

故 `(1+η)D−ηG<0`，同时原猜想缺口 D 最终为正。
同一构造排除所有 0<p<2 的普遍正余项
`D ≥ c Gᵖ/Tᵖ⁻¹`。
二次余项未被该构造排除，也未被证明。

详情：[density-gradient.md](density-gradient.md)。
这项结果只否定该更强的普遍辅助不等式；
它不否定原猜想，也不排除利用自洽方程的优化子专用估计。
