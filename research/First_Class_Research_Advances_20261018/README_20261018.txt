第一类研究续稿：负能量相干动力学
日期：2026-10-18

本次只推进第一类：质量临界聚焦色散方程的负能量相干结构、全局解及质量阈值。
这是一个工作的三项相互关联的加强；不是将主线拆成三篇论文。

一、实际新增结论

1. 单核心加辐射的精确零动量全局解。
   对已有四维 cubic BNLS 的小速度负能量分支 Q_v，构造一个前向全局、
   一致 H^10 有界的真实解，渐近为运动核心加自由辐射。
   总动量严格等于零，总能量严格小于零，质量 M(Q)+O(v^(2/3))。
   旧双核心构造的质量极限为 2M(Q)，本次降到 M(Q)。
   对固定核心 P(Q_v)=-q_v e_1，辐射质量的尖锐下确界为
       mu_crit = q_v (4/v)^(1/3).
   所有 mu > mu_crit 均可构造；mu <= mu_crit 不可能保持总负能量。
   这是指定核心加自由辐射渐近类的精确阈值，不是所有全局解的最小质量。

2. 无空间矩的定量行波残差排除。
   对一般 m>1 次齐次实偶正椭圆色散，归一化 A(U)=1，质量在 Mc 附近且
   E(U)<0 时，inf_{omega,v} ||R_{omega,v}(U)||_{H^(-m/2)} >= c |E(U)|。
   不需要有限方差、优化子唯一性或实部线性化非退化。
   相比旧 R9，去掉了额外 dilation-defect 条件；线性幂在该范围内最佳。
   证明通过有限维边框隐函数定理及缩放协变性恢复合法的缩放可微性。

3. 三变量 cubic 混合阶模型的统一质量间隙。
   对 -partial_x^2 + Delta_y^2 - mu Delta_y，x 属于 R，y 属于 R^2，mu>=0，
   行波的内禀能量 E_mu(U)-P_x(U)^2/(2M(U)) 为负时，M(U)>=Mc+delta。
   同一个 delta 对 mu、频率及全部速度统一。也覆盖 y 中正半定二次形式。
   关键是二阶方向的精确部分伽利略变换，然后使用同一相位强制性机制。
   进一步，第二项的无空间矩残差定理已推广到本混合模型的全部近临界状态，
   对任意正半定横向二阶色散矩阵 K 统一。先移至 P_x=0 的参考系后，
       |E_int(U)| <= C inf_{omega,v} ||R_K(U)||_{H_a^*}。
   因此这里的精确行波间隙是同一个稳健残差原理的直接推论。
   新模型中的负内禀能量行波存在性尚未证明。

附录：两个显式 Fourier 平方恒等式给出纯 BNLS 行波的能量、频率、速度界，
例如 E(U)>-||Delta U||_2^2/16。常数在概率矩问题中尖锐，未证明在非线性剖面
类中尖锐。最小行波质量端点仍未解决。

二、共同机制与当前最重要的未解问题

共同机制是临界缩放、动量和相位二次型对负能量的共同约束。
构造一侧回答负能量如何通过核心运动及辐射分流持续存在；排除一侧回答
临界质量附近为什么不能静止或近似行波化；混合阶扩展检验这一机制的适用范围。

最重要的未解问题仍是：是否存在统一的近 Mc 质量窗口，排除所有零动量、
负能量、前向全局且 H^2 一致有界的纯 BNLS 解？新残差估计不能自动排除
循环变形。单核心构造的质量趋于激发态 M(Q)，并非趋于基态临界质量 Mc。
